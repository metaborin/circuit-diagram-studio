# 回路図スタジオ

高校電気科の計算問題・テスト・授業プリントに使う、白黒の電気回路図を作成するブラウザツールです。回路図を決定的な SVG で描画し、図としての接続・記号・ラベルを編集できます。電流・電圧の計算やシミュレーションは行いません。

- アプリ: https://metaborin.github.io/circuit-diagram-studio/
- ソースコード: https://github.com/metaborin/circuit-diagram-studio

## できること

- 電池、直流電源、交流電源、抵抗、コイル、コンデンサ、開閉スイッチ、電流計、電圧計を配置・移動・90 度回転・複製・削除。
- 抵抗の長方形記号とジグザグ記号を切り替え。
- 20 単位のグリッドにスナップする配置と直交配線。部品の移動・回転時も配線端点は部品端子に追従。
- 接続点・端子・分岐、配線の経由点、横→縦／縦→横の経路を編集。
- 記号、値、単位、添字、周波数・位相などの補足を編集。`R_1` / `R_{12}` / `R₁` などの添字、`Ω` / `mH` / `μF` に対応。
- 問題用に値を `?` または空欄に変更、ラベルを非表示。ラベル位置も調整可能。
- 電流方向、電圧・極性、任意のテキスト注記を追加。
- Undo / Redo、未保存の編集があるときの図切替確認、空白図の作成時の確認。
- 白黒 SVG、白背景の高解像度 PNG、ブラウザの印刷・PDF 保存。出力には編集用グリッド・選択枠・端子ガイドを含めません。
- 編集可能な JSON の保存・再読み込み。ブラウザ内への作業中データの自動保存。

16 種類のひな形があります。直流基本回路、抵抗の直列・並列・直並列・ブリッジ、コンデンサの直列・並列、交流 R・L・C 単独、RC・RL・RLC 直列、RLC 並列・直並列、電流計・電圧計の接続を用意しています。交流ひな形の `RMS` は実効値を意味します。入力値が実効値か最大値かは自動判定しません。

## 基本の使い方

1. 「ひな形」から近い回路を選ぶか、「空白の図を作成」から始めます。初回はひな形を表示し、選ぶと部品のパネルへ進みます。ブラウザ内の下書きから再開するときは部品を表示します。
2. 左の部品を選んで図の中をクリックします。配置した部品はドラッグ、矢印キー、プロパティの座標で移動できます。図の部品・配線・接続点・注記は Tab でフォーカスし、Enter / Space で選択することもできます。
3. 「配線」を選び、始点・終点の端子を順にクリックします。配線上をクリックすると、その配線を分割して分岐を作れます。空白をクリックすると途中の折れ点を追加でき、`Esc` で終了します。
4. 部品を選び、右のプロパティで記号・値・単位・表示方法・向き・ラベル位置を整えます。
5. 「編集データを保存」で続きから編集できる JSON ファイルを保存し、「図を書き出す」で PNG / SVG / 印刷・PDF を選びます。

作図領域の上には現在の操作と次の手順を表示します。追加・配線をやめるときは「選択に戻る」または Esc を使います。「全体表示」は図全体を作図領域に収める倍率へ切り替えます。PC の左右のパネルは必要に応じて内部をスクロールできます。

「ブラウザに自動保存済み」は端末内の下書き、「編集データは保存済み」は現在の内容を JSON ファイルへ保存または読み込んだ状態です。編集すると「編集データは未保存」になります。ブラウザの下書きから再開しただけではファイルの保存状況を確認できないため、「編集データの保存を確認」と表示します。

### 接続と交差のルール

**配線は端子・接続点への明示的な接続で管理します。図形を重ねるだけでは電気的に接続しません。** 接続されていない配線の交差は隙間で区別し、分岐の接続は黒丸で示します。

既存の交差を接続に変えるには、配線上に接続点を置いて選択し、「この位置の配線を結合」を押します。部品を動かしたり、接続点を他の配線上に重ねたりする操作だけで、別の配線が自動的につながることはありません。削除した部品・接続点につながる配線は一緒に削除されます。

配線を選ぶと曲がり方や経由点を変更できます。端点を変えるときは配線を削除し、接続し直してください。配線の経由点は線の形を指定するための座標で、それ自体は電気的な接続点ではありません。

### 出力と保存

- **PNG:** 白背景で標準 3 倍解像度。Word やスライドへの貼り付けに使えます。画像が極端に大きい場合は解像度を調整します。
- **SVG:** ベクター形式。拡大しても線がぼけません。日本語文字の見え方は開く端末のフォント環境によって変わります。
- **印刷 / PDF:** 印刷用の別画面を開きます。ブラウザの印刷ダイアログで送信先「PDF に保存」などを選んでください。専用 PDF ファイルを直接生成する機能ではありません。ブラウザの設定によってはポップアップの許可が必要です。
- **JSON:** 別の端末でも再編集できる保存形式です。「編集データを開く」で読み込みます。SVG・PNG の読み込み・図形への再変換には対応しません。

ブラウザ内保存は同じ端末・同じブラウザ・同じサイトの作業再開を助ける補助機能です。クラウド同期やバックアップではありません。プライベートブラウズ、保存領域の削除、ブラウザの容量制限などで失われることがあるため、大切な図は JSON として保存してください。

本番ビルドは PWA・サービスワーカーに対応しています。オンラインで開いて「オフラインで利用できます」と表示されるまで準備すると、オフラインでも再訪・編集・書き出しができます。アプリのキャッシュが削除された場合はオンラインで再準備してください。手順と利用条件は下記「アプリとしての利用・オフライン・更新」を参照してください。

作成した回路図はブラウザ内で処理します。アプリから図や個人データを外部サーバーへ送信する機能はなく、外部 AI API・有料 API・ログインは不要です。GitHub Pages からのアプリ配信には通常のネットワークアクセスが発生します。

## ショートカット

| 操作 | キー |
| --- | --- |
| 選択ツールへ戻る・配線終了 | `Esc` |
| 選択中の部品・注記を 90 度回転 | `R` |
| 選択中の図形を 1 グリッド移動 | 矢印キー |
| 選択した項目を削除 | `Delete` / `Backspace` |
| 元に戻す | `Ctrl+Z` / `Cmd+Z` |
| やり直す | `Ctrl+Y` / `Cmd+Y` / `Ctrl+Shift+Z` / `Cmd+Shift+Z` |

入力欄の編集中は、図形操作のショートカットを実行しません。

## 初版の範囲と制限

- 二端子の集中定数回路を中心に扱います。すべての高校回路・電気記号を網羅するものではありません。変圧器、半導体、三相専用記号などは未対応です。
- 電気量の計算、単位の正誤判定、解答生成、回路動作のシミュレーションはありません。未接続・近接などの表示は補助的な警告であり、回路問題の正解を保証しません。
- 自動配線は単純な直交経路です。障害物の自動回避・ラベルの自動衝突解消はありません。配線の経由点とラベル位置を調整してください。
- 異なる接続網の配線が同一直線上で重なる、未接続端子が配線と重なる、配線が部品本体を貫くなど、接続を誤読しやすい図は書き出しを止めて修正を案内します。通常の開放端子や、隙間で区別された非接続の直交交差は出力できます。
- 電流・電圧の注記は独立した図形です。部品を動かしても注記は追従しません。出題する向き・極性との一致を確認してください。
- 編集領域は固定サイズです。狭い画面ではパネルの並びが変わり、図の横スクロールが必要になる場合があります。主な編集用途は PC・Chromebook を想定しています。
- JSON は独自形式 `version: 1`。破損した参照、重複 ID、非有限数、過大な配列・文字列などを拒否します。読み込みファイルは 2 MB 以下、配線の直線区間は合計 1200 以下です。長さゼロの配線も上限では 1 区間に数えます。

## 開発・ローカル起動

Node.js 22 系と npm を使用します。

```sh
npm ci
npm run dev
```

表示されたローカル URL をブラウザで開きます。開発サーバーは既定で `127.0.0.1` にバインドします。

```sh
npm run lint
npm run typecheck
npm run test
npm run build
npm run preview
```

接続モデルのテストでは、各ひな形の節点数、回転・移動後の端子追従、直交経路、非接続交差、明示結合、分割、不正 JSON などを検証します。出力のテストでは SVG の安全な文字列処理、白黒表示、編集ガイドの除外などを検証します。ブラウザ操作のテストを実行する場合は、Playwright のブラウザを準備して `npm run build` → `npm run test:e2e` を実行します。PWAテストは生成済みの `dist` を専用の一時ローカルサーバーで検証します。既存の開発サーバーを再利用せず、必要なら環境変数 `PLAYWRIGHT_PORT` でテスト用ポートを選べます。

技術構成は React / TypeScript / Vite。描画は SVG で、画像生成モデルを使用しません。依存関係の再現には `package-lock.json` を使用します。

## GitHub Pages への配置

`.github/workflows/pages.yml` は `main` への push で lint・単体テスト・型検査を含むビルドを実行し、生成した `dist` を GitHub Pages に配置します。リポジトリの **Settings → Pages → Source** を **GitHub Actions** に設定してください。必要な権限はワークフローに指定しています。

Vite の `base`、manifest の `id`・`start_url`・`scope` は `/circuit-diagram-studio/` です。別の場所へ配置する場合は、これらと `scripts/build-pwa.mjs`、`scripts/service-worker.template.js` のパス・キャッシュ専用名、アプリ内の GitHub リンクを合わせて変更してください。

## アプリとしての利用・オフライン・更新

本番ビルドでは、対応する Chrome / Edge のインストールボタンやブラウザメニューからアプリとして追加できます。未対応のブラウザでも通常のWebページとして利用できます。インストールそのものは必須ではありません。開発サーバーではService Workerを登録しません。

初回はオンラインで開き、「オフラインで利用できます」が出るまで待ってください。表示前には本体・CSS・全アイコン・manifestを含むビルド資産の保存を確認します。その後は回路図の編集、JSON / SVG / PNG保存、印刷用画面をオフラインで利用できます。PDFは従来どおりブラウザの「PDFに保存」を使用し、追加サービスやフォント配信への接続は必要ありません。端末にあるフォントやブラウザの印刷機能により結果は異なります。実機Chromebookのインストールや印刷操作は別途確認が必要です。

新しい版があっても、編集中に再読み込みや強制切り替えは行いません。案内が出たら「編集データを保存」で図を保存し、回路図スタジオのすべてのタブ・アプリ画面を閉じて開き直してください。更新機構が独自に図の保存データを書き換えることはありません。図の保存キー `circuit-diagram-studio:v1` とJSON形式 `version: 1` は維持しています。

ブラウザのデータ削除や容量不足によるキャッシュ削除の後は、再度オンラインで準備が必要です。重要な図はJSONファイルにも保存してください。キャッシュは `metaborin/circuit-diagram-studio/<20桁のビルドハッシュ>` に限定し、他アプリのキャッシュを読み書き・削除しません。SWは同一オリジンの `/circuit-diagram-studio/` 配下のGETだけを扱います。`npm run build` の最後に全ビルド資産からSWを生成するため、`vite build` だけを実行して配置しないでください。

アイコンは当プロジェクト用の回路記号を幾何図形で描いたオリジナルです。192 / 512px PNGと、記号を中央の安全領域に置いた不透明背景のmaskable PNGを同梱します。再生成は `node scripts/generate-icons.mjs` で行えます。
